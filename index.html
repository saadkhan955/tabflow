🔒 Local-First Architecture • Direct Privacy

Zero Middleman Servers

Your TabFlow settings, preferences, and tab states are stored locally on your device. All Google authentication and YouTube actions communicate directly with Google's official endpoints over encrypted HTTPS. TabFlow never operates an intermediary database or collects user telemetry.

✓

No External Databases

Your OAuth tokens, playlist preferences, and tab titles are stored strictly in local Chrome storage on your machine.

✓

Minimal Permissions Only

TabFlow requests only tabs (to find YouTube video links), storage (for theme preferences), and identity (for direct Google OAuth).

✓

Google API Limited Use Compliant

TabFlow strictly adheres to the Google API Services User Data Policy. We never sell, monetize, or transfer your data.

✓

100% Open Source

Every line of code is open source and inspectable on GitHub by developers and security reviewers.
