Privacy Policy

Last Updated: September 4, 2026 • Effective Date: January 1, 2026
Core Privacy Summary: TabFlow is a client-side browser extension built on a local-first architecture. TabFlow does NOT own, operate, or maintain any external database servers. We do NOT collect, sell, monetize, track, or transmit your personal data, browser history, or Google credentials to any third parties. All interactions with the YouTube Data API occur directly and securely between your browser and Google's official API servers.

1. Information We Access and How It Is Used

TabFlow only accesses the minimum necessary browser permissions and Google APIs required to execute user-requested actions:

  • Open Browser Tabs (tabs permission):

    Used strictly in local memory to inspect active browser tabs to detect open YouTube video URLs (matching youtube.com/watch, /shorts/, /live/, or youtu.be) and extract video titles and IDs. Tab URLs are processed locally and are never stored on external servers or transmitted to third parties.

  • Google Identity & YouTube Data API v3 (https://www.googleapis.com/auth/youtube & https://www.googleapis.com/auth/youtube.force-ssl):

    When you explicitly connect your YouTube account via Google OAuth 2.0, TabFlow uses temporary authorization tokens solely to perform explicit user-initiated actions via the official YouTube Data API v3:

    • playlists.list: Display your existing playlists in the dropdown menu.
    • playlists.insert: Create new public, unlisted, or private playlists upon your direct request.
    • playlistItems.insert: Batch add selected video tabs into your chosen playlist.
    • playlistItems.list: Retrieve video entries within a playlist to detect duplicates.
    • playlistItems.delete: Remove confirmed duplicate video entries when you click "Clean Duplicates".
  • Local Storage (storage permission):

    Used to store your local interface preferences (such as dark mode toggle, auto-close tabs preference, and temporary client-side cache) directly in your browser's local chrome.storage.local. This data never leaves your device.

2. Data Protection Mechanisms for Sensitive Data

We implement comprehensive technical and organizational data protection mechanisms to secure all sensitive user data, access tokens, and API communications:

Security & Data Protection Standards:
  • Encryption in Transit: 100% of network requests to Google OAuth and YouTube Data API endpoints are strictly enforced over Transport Layer Security (TLS 1.2+ / HTTPS). Plaintext or unencrypted data transmission is technically impossible.
  • Encryption at Rest & Local Sandboxing: All OAuth tokens, cached playlist IDs, and user settings are stored locally within Chrome's sandboxed, origin-isolated chrome.storage.local database on your device. TabFlow does not maintain any external backend servers, remote databases, or cloud storage.
  • Ephemeral Memory Processing: Tab titles, URLs, and video metadata are processed transiently in memory during active browser sessions and are purged immediately upon completing the playlist save action or closing the popup.
  • Principle of Least Privilege: Tokens are requested with minimal required scopes and are held ephemerally. Tokens are never logged to console outputs, exported, or shared.

3. Google API Services User Data Policy & Limited Use Compliance

TabFlow's use and transfer of information received from Google APIs strictly adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically:

  • We only use access to YouTube Data API data to provide and improve user-facing features that are prominent in the user interface.
  • We do not transfer or disclose your Google user data to third parties.
  • We do not use your Google user data for serving advertisements, including retargeting, personalized, or interest-based advertising.
  • We do not use your Google user data to train generalized AI or machine learning models.
  • Human beings do not read your data under any circumstances.

4. Data Retention, Revocation, and Deletion

Because all data is processed locally in your browser session, TabFlow does not retain your data on external databases:

  • In-App Sign Out: Clicking "Sign Out" inside the TabFlow settings immediately purges all active OAuth tokens and temporary playlist caches from local storage.
  • Google Account Revocation: You can revoke TabFlow's access to your Google Account at any time by visiting Google Account Permissions.
  • Extension Uninstallation: Removing the extension from Chrome immediately and permanently deletes all locally stored preferences and sandboxed data from your machine.

5. Third-Party Services and Telemetry Disclosure

TabFlow contains zero third-party analytics trackers, cookies, or telemetry libraries. The extension communicates directly only with:

  • https://www.googleapis.com — Official Google & YouTube Data API endpoints.
  • https://accounts.google.com — Official Google OAuth 2.0 authentication service.
